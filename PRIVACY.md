# Privacy Policy

Retro Focus Blocker is designed to be privacy-first.

This document explains what data the extension uses, where it is stored, and what is not collected.

## Summary

Retro Focus Blocker does not collect, sell, or share personal data by default.

The extension is designed to work locally in your browser.

## Data Collection

By default, Retro Focus Blocker does not collect:

- Personal information
- Browsing history
- Analytics events
- Camera recordings
- Camera images
- Account information
- Payment information
- Location data

## Local Storage

The extension may store settings locally using Chrome storage.

This can include:

- Blocked website list
- Focus timer preferences
- Rest timer preferences
- Spotify URL preference
- Presence Guard settings
- Extension state needed for focus sessions

This data is stored locally in your browser and is not sent to a server by default.

## Website Blocking

Retro Focus Blocker checks whether visited websites match your blocked-sites list during an active focus session.

This is used only to redirect distracting sites to the blocked page.

Blocked-site settings are stored locally.

## Camera Access and Presence Guard

Presence Guard is optional.

If you enable Presence Guard, the extension may request camera permission from your browser.

Camera access is used only to detect whether someone appears to be present in front of the laptop during a focus session.

Depending on browser support, Presence Guard may use:

- Face detection when available
- Motion or presence fallback when face detection is unavailable

Camera frames are not uploaded to any server by default.

The extension does not store camera recordings by default.

The extension does not sell or share camera data.

## Spotify Support

Retro Focus Blocker can open a Spotify URL when a focus session starts.

The default URL may point to Spotify liked songs, but you can replace it with your own playlist, album, or track URL.

Retro Focus Blocker does not include Spotify account login, Spotify OAuth, or direct playback control by default.

## Notifications and Audio

The extension may use browser notifications and browser-based audio alerts for:

- Focus complete
- Rest complete
- Presence Guard missing alert
- Manual sound test

Audio alerts run locally in the browser.

## Analytics

Retro Focus Blocker does not include analytics by default.

If a fork or modified version adds analytics, cloud sync, accounts, or remote logging, that version should clearly disclose what is collected and why.

## Data Sharing

Retro Focus Blocker does not sell user data.

Retro Focus Blocker does not share user data with advertisers.

Retro Focus Blocker does not send focus data, blocked-site lists, or camera data to external servers by default.

## Children and Students

Retro Focus Blocker may be useful for students, but it is not a school monitoring product by default.

It does not provide teacher dashboards, parent dashboards, remote monitoring, or cloud reporting by default.

## Security

If you find a privacy or security issue, please report it responsibly.

See `SECURITY.md` for reporting instructions.

## Changes to This Policy

This privacy policy may be updated as the project changes.

If new features introduce data collection, cloud sync, accounts, analytics, or remote storage, this document should be updated before release.

## Contact

For privacy questions, open an issue on the GitHub repository.
