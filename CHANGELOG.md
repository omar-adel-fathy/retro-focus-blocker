# Changelog

All notable changes to Retro Focus Blocker will be documented in this file.

This project follows a simple versioning style:

```text
MAJOR.MINOR.PATCH
```

Example:

```text
1.0.0
```

## [1.0.0] - 2026-05-16

### Added

- Initial release of Retro Focus Blocker
- Focus timer presets
- Custom focus session length
- Countdown timer in the popup
- Editable blocked-sites list
- Default blocking for common distraction sites
- Retro terminal-style blocked page
- Rest break suggestions after focus sessions
- Custom rest timer support
- 2-minute bathroom/water break mode
- Retro beep/siren-style sound alerts
- Optional camera-based Presence Guard
- Face detection support when available
- Motion/presence fallback when face detection is unavailable
- Spotify URL support
- Local Chrome storage for settings
- Chrome notifications support
- Privacy-first setup with no analytics by default
- MIT License
- README documentation
- Contribution guidelines
- Privacy policy
- Security policy

### Notes

- This is a browser extension, not an operating-system-level lockdown tool.
- Users can still disable the extension, close Chrome, mute device audio, or shut down their laptop.
- Presence Guard requires camera permission and is optional.
- Spotify direct playback control is not included because it requires Spotify API setup, OAuth, and usually Spotify Premium.
